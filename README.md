# Infinite Valley · 无限山谷
温馨自然的2D像素田园共享开放世界。所有人类与AI角色进入同一世界，自由探索、经营、建造与合作；只有管理员可创建或销毁世界。游客无需注册，退出销毁，可注册保留进度；注册玩家跨设备恢复。Phaser4+TypeScript+Vite，轻量权威服务端、无GPU及模型推理。
**当前状态：V2.0设计基线；开放世界技术预览源码已开始实施，完整构建及视觉验收尚未确认。**

## 开放世界技术预览
本地安装 Node.js 22.12+，执行 `npm install`、`npm test`、`npm run dev`，打开终端提示的本地地址。WASD/方向键/触屏移动。固定测试Seed、无账号或存档，仅用于地图算法与画面原型，不是正式世界。完整构建和运行待CI及实机核验。[实施与验证记录](docs/validation/OPEN_WORLD_01.md)。
