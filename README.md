# Infinite Valley · 无限山谷

温馨自然的 2D 像素田园开放世界。探索自然，选择家园，采集、种植、制作、建造、养殖与经营。以浏览器本地运行、无后端游戏计算为目标。

**状态：正式设计阶段；尚无可运行游戏。** 当前不提供虚构的安装命令或 Demo。
