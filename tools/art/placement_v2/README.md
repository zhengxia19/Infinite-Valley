# 地图组合 V2 · 区域级离线原型
保留 32px 网格和已批准 PNG，不替换正式生成器、不改变唯一共享世界。生成实际源图嵌入的 SVG 景观；不使用生成式整景代替。
## 执行
`node tools/art/placement_v2/compose.mjs . /tmp/iv-placement-v2 2701`；`node tools/art/placement_v2/test.mjs`。不需要新增 npm 依赖。浏览器打开输出 SVG。节点桥接沿实际桥面多边形像素路径，陆地网格通过经过干地的连接段接到入口；不把整块水格直接打开。
## 变化
- 曲线河岸按距离生成浅水、深水、岸边泥土带；草地使用原纹理混合，路径从实际入口生成。不是全材质 autotile。
- 三种建筑随机候选落点、干地检查、占地排斥、门口连通、院落铺砖与两级台阶。水车仍需专项约束。道路仅验证中心线，尚需宽度碰撞。
- 正交桥及三款斜桥使用源图测量几何、干地入口和支点、桥面像素连通与正交网格入口。不是 Phaser 的正式移动实现。
- 屋顶、树冠、桥栏采用多边形裁切为基础/前景绘制项，边界是待验收的初始近似，不是独立美术图层，可能遮到桥面或墙体。
- 种子改变河道、建筑位置及道路；当前为有限区域样片，不能直接写入正式世界，跨 chunk 所有权及服务器权威尚未实现。
## 验证
见 validation.json，工具环境实际运行同一 JS 函数的种子与确定性检查；未运行 Node CLI、浏览器视觉渲染和正式引擎。新样片待用户确认。
