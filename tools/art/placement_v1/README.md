# 地图组合机制 V1：离线诊断样片
用户要求修复桥梁、建筑与道路的组合关系。本批未修改任何已批准美术 PNG，也没有增加素材类型。以32px地形、48×64人物、既有源图和V1候选树木/木屋等做真实离线合成，不以AI生成整景代替。
## 运行
从仓库根目录：python tools/art/placement_v1/compose_placement.py . /tmp/iv-placement 2701
依赖 Pillow、NumPy、SciPy。实际运行环境 Pillow 12.3.0、NumPy 2.3.5、SciPy 1.17.0。输出PNG、连接标记、validation.json。仓库previews为实际输出转码JPEG，仅查看；PNG可按脚本再生。
## 结果
- 51个输入PNG的Git blob SHA均与提交前main完全一致。
- 1152×768，146个物体与人物实例；种子2701复跑景观PNG和报告逐字节一致；2702、2703同一固定诊断几何下仅随机装饰变化，所有断言通过（152/142实例）。
- 正交直桥：道路使用实测入口A/B，水中通行由明确桥面多边形开放；32px采样逻辑格BFS跨岸通过，去掉桥格后两岸不连通。入口水中、道路缺口、跨度不足（降低允许跨距测试）、不兼容朝向四类负例拒绝通过。
- 木屋、蓝瓦店铺、水车、摊位：四处脚印干地、入口干燥且不被自身足迹阻挡、连接道路，像素掩膜BFS均可达南岸。水轮标定点在水中。水车的入口及身体几何仍是人工校准初值。
- 石拱桥、木索桥、石阶桥：分别在独立弯曲河道中用源图校准视觉入口与桥面、支承点，像素掩膜检查通过；三者未适配正式正交逻辑格，不能自动加入正式世界。
- 地表多纹理融合、连续曲线河岸、摆放排斥及脚底排序为离线方案；未完成跨材质通用autotile、真实分层遮挡、完整实体碰撞、动画或网络。使用手工校准的固定诊断布局，不等同通用自动村庄生成。连接掩膜是几何测试，不保证所有可见像素完全合理。
