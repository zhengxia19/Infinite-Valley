# 开放世界第一批实施
本次优先实现 G3-02 可复用纯地表核心，不改变唯一正式共享世界架构。
已实现32×32 Chunk、512×512 Region常量、负坐标、固定NFC种子哈希及多尺度Simplex高度/湿度/温度场、地表分类、资源稳定ID、1格halo及8邻域mask、25区块缓存和只读预览出生点。
验证：在V8隔离环境执行同一源码擦除类型后的实现及同一测试主体，4组通过：30种子×4位置跨区边界/逆序/资源归属、1000区块缓存上限、负坐标/Unicode、坐标边界。不是Node原生测试、浏览器测试或内存实测。CI与正式运行尚待执行。
尚未完成：区域河流/道路/村庄、正式出生点BFS、权威服务器及共享增量、正式美术、客户端/服务器黄金hash。当前地表水域仅低洼地形；生成器版本仅测试预览，不可用于正式世界。G3-02尚未验收。
