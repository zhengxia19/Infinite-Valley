## 当前环境实际核实
- ChatGPT 原生图像生成：原创概念、参考图编辑、角色与动作原稿；使用现有服务额度，不增加订阅或 API Key。输出不保证原生像素网格、图层、方向或独立关键帧正确，必须后处理。
- Python：Pillow 12.3.0、NumPy 2.3.5、SciPy 1.17.0、OpenCV 4.13.0、scikit-image、imageio、pytest 均可导入或已确认模块存在。用于分割、裁切、透明化、nearest 像素对齐、色板、图层及图集、图像检测。
- ImageMagick 7.1.2、FFmpeg 7.1.5：可执行程序已存在，用于无损转换、合成、动画预览。
- Chromium 144、Playwright、Node/npm：已存在；可执行自包含浏览器预览及具备依赖时的游戏渲染验证。依赖、真实场景和真机仍须实际运行确认。
- GitHub 连接器：已成功读写仓库；容器直接 git ls-remote 仍因 DNS 无法解析 github.com 失败。二进制素材必须逐次验证可读取、传输、提交并核对 blob SHA，不能把文本提交当作图片入库。
- 不使用 PixelLab、fal、Scenario 或付费 Aseprite。不要求用户额外安装 LibreSprite、Pixel Studio、SpriteKiln、ComfyUI、Pixelorama；本环境未接入这些工具，也未发现可用 NVIDIA GPU，不能承诺本地扩散模型生产。无需额外插件授权。

## 当前生产流程
1. 以用户已确认的原创主视觉、角色样本为基准；缺少实际原图时先恢复可用源图，不能用独立建筑参考替代。
2. 原生图像生成提供独立素材原稿；Python/OpenCV 提取独立对象、校准尺度、透明背景、脚底锚点，保持原生像素边缘。分层采用独立实际遮挡层；不得将换色、自动分割或插帧夸大为不同剪裁或独立手绘姿势。
3. Pillow/NumPy 输出 PNG/JSON、命名、图层、动画及地形边角。执行 tools/art/check_character_atlas.py 对未裁切硬透明角色图集进行只读检查；地形需额外邻接检查。ImageMagick/FFmpeg 输出预览，Chromium/Playwright 验证交互。不能以离线预览替代 Phaser 实景。
4. 候选素材先由用户确认，保持 D09 ART01–05、C26 与 G3 门禁；通过后再提交正式素材。生成记录、原稿及许可必须可追溯，禁止秘密入库。
5. 工具仅供开发使用，不新增游戏运行时依赖或服务器模型推理。

## 试产与验收任务（当前工具链）
现有基准：character_v2 男/女已视觉批准，48×64、3–3.5头身、32px地面、四向、4待机/8行走；现有6类同轮廓换色+帽子并非真正不同剪裁换装。农业动作原稿已批准，64×80扩展画布、脚底锚点32,65，工具/服装烘焙、4关键姿势；不是完整分层动画。严禁战斗、地下、死亡内容；此前独立建筑参考继续废弃。
- ART-T01：以已验收男性 V2 为参照，生成四向待机/行走和跑步小样；目标保留造型、方向、光照，足底定位一致。记录实际独立关键帧与补帧方式，不以重复图充帧。
- ART-T02：同一角色身体、不同轮廓发型/上衣/裤装/鞋履以及工具层；通过各帧叠加和遮挡检查验证真正换装，不能只换色。
- ART-T03：同一套32px地块、自然边角、树、水、道路、田地、木屋和围栏；构建农场及自然两组固定场景，房屋须在场景整体评审，不单独确认。
- ART-T04：将现有基准与新工具结果放在相同实际像素尺度，进行1×、2×、四向动作播放及 Phaser 固定 Seed/时刻/相机截图。逐项记录通过/不通过、人工修整时间、重试次数与新增服务费用（应为零）。不得以概念图替代引擎截图。用户逐批确认前仅放 assets/candidates/，不进入正式资源、不启动批量生成。
- 评价维度：原生像素质量、造型/色板一致性、真实动作、换装分层、邻接接缝、返工成本、授权。规格/许可/真实场景为硬门禁，不自行设定分数或批准阈值。
- 每批保存原稿、生成参数/工具版本/任务ID、实际 PNG/JSON、可复现脚本、许可记录及测试证据；用户确认后提交；D09 ART01–05 与 G3 门禁维持不变。
