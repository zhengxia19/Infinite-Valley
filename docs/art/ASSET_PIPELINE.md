## 生产流程
1. 先由设计师/AI 依据两个主锚点制作同一风格板：草地/泥土/水岸、树木、农田、木屋、角色、道路、围栏；不得将完整概念图当作可重复游戏地图。
2. 制作原生像素素材；生成模型可用作概念和单独素材初稿，程序裁切、调色、去背景、像素对齐、检查 alpha，人工修整。源图/提示/生成工具版本登记（不提交个人秘钥或无权公开输入）。
3. 输出地块边缘/角/内外角和变体、静态物体与四方向角色动画。设计两个可实时交互的完整场景，执行 ART01–05；按下述强制门禁交付，用户确认实时场景再扩展。
4. 批量生产季节树/地面/屋顶、作物阶段、建筑/室内、动物与物品。每批检查相同投影、比例、光照、色板和轮廓。
5. 工具脚本生成 atlas PNG + JSON、类型/尺寸/锚点/碰撞元数据及校验报告；从源资产可复现。图集按场景/季节/实体分组；初值1024或2048边长（真机预算），padding/extrude 2px、防止纹理渗色，nearest。不要每个 chunk 复制纹理。

## 实时渲染交付与用户验收（2026-11-27，强制）
用户明确要求：所有后续生成、重制或扩展的素材，在请求用户确认前，必须使用本批实际生成并处理的独立素材实时拼接为完整可交互游戏场景。不得将单张素材、静态图集、AI生成的完整概念图、离线合成图片、截图、GIF或录屏作为用户确认交付物。原稿与截图仅用于内部制作、归档和回归证据，不作为用户验收入口。
- 流程：生成原稿 → 裁切/透明处理/像素对齐 → 生成图集与锚点、碰撞及遮挡元数据 → 加载实际资产实时渲染 → 实测交互与组合 → 提供可直接操作的预览入口 → 用户明确确认 → 转正式资产并提交。保留原稿、生成记录和复现配置。未获确认不得替换已批准正式资产。
- 采用项目现有 Phaser 4 渲染体系，不另建第二套正式引擎。可在隔离的验收场景或技术预览中加载候选资产，不影响唯一正式世界。必须在浏览器实际运行；无法提供可操作预览时如实记录阻塞，不以静态图片替代，不请求视觉验收。
- 根据批次选择完整农场/村庄、自然生态、室内等场景；本批每个新增或变更的资产ID及重要状态均须有可达的展示位置，和已批准环境、人物保持真实比例。不得把完整背景图、整张原稿或未实际生成的占位素材当作场景组件。允许多个关联验收场景，不强塞在同一视口。
- 基础交互：人物键盘移动（WASD/方向键）、触屏移动、镜头跟随或平移、整数倍率缩放；适用时支持四季/昼夜/天气切换、动作播放、进入与离开遮挡、跨桥、门与围栏交互。地形拼接、道路连接、锚点、层排序、碰撞和动画使用实际资产及运行逻辑，不能通过固定截图模拟。尚未实现的玩法须标注，不宣称通过。
- 提供可打开的实时预览入口、操作说明、批次ID、仓库commit、场景seed及资产清单/版本，并记录实际浏览器测试及缺陷。用户无需查看或下载素材图集才能验收；不额外提供下载包，除非用户明确要求。截图只作为可复现的辅助证据。
- 验收状态区分母版方向确认、技术处理完成、实时场景待验收、用户实时场景确认和正式集成。既往已确认母版保持历史状态，不推定实时场景已通过，也不因此重新生成已确认素材。当前五组环境组件需进入实时组合预览；重制树木不得通过独立图片确认。

## 目录与命名（计划）
assets/source/{terrain,props,characters,crops,buildings,ui,audio}/；public/assets/ 仅构建产物，按内容 hash；docs/art/reference/ 存获授权或自产的批准截图与配置。ID lower_snake_case；frame 名如 tree_oak_summer_idle_00，角色 walk_south_00。图像 PNG RGBA，禁止带有半透明白边/水印/不可解释抖动。动画同动作帧尺寸一致、脚底锚点固定；动画时序独立于游戏时钟（暂停时冻结）。地表每格32px；人物48×64（用户已确认）；大物体 footprint 独立。碰撞不从透明像素推断，显式矩形或占地格。
元数据字段：assetId, sourceFile, atlasFrame, width, height, anchorX/Y, footprint, collision, occlusionParts, season, animations[{name,frames,fps}], licenseRef。anchor 使用源像素坐标，树/人物脚底、建筑门附近接地点，渲染时转换局部坐标。

## 资产校验
- 图集帧不重叠、不越界，动画缺帧/命名重复、未知素材引用、缺少授权记录视为失败。
- autotile 对边/角邻接组合全覆盖，跨 chunk 截图无缝；随机变体使用稳定坐标 hash。
- 颜色不机械量化破坏已确认美感；同物种/建筑同一季节的光源一致。遮挡单独层，透明切换不改变碰撞。
- 所有资产测试1×/2×及移动端适配倍率；保持像素边缘，禁止插值模糊。
- UI icon 32px，文字不烘焙到图，简中英文共用素材。
- 音频：轻柔田园 BGM（建议3首或按季4首，待授权），风/水/鸟/雨等环境循环、工具/拾取/界面音效；优先 Ogg/兼容格式按真机验证，循环点无爆音，分别音量，静音不影响玩法。首次交互前不自动播放。音频按需下载，不拖慢首屏。
