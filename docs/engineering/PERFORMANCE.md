# 性能设计与资源预算 D12
v1.0 · 2026-11-27 · 全部为目标及初始约束，未实测
依赖 D05、D09、D10。重点是移动端可玩与无限探索内存有界，不追求服务器并发计算。

## 目标环境
PC Windows10/11 Chrome/Edge 当前稳定版，集显基线（建议 Intel UHD 620 等级，8GB RAM）；手机 Android 中端骁龙778G/6GB等价、Chrome，另测 iOS Safari 兼容机型（若无真机，不宣称通过）。设备型号、GPU、OS、浏览器版本/DPR、图形档位、屏幕分辨率记录实测。性能目标：PC60FPS，手机≥30FPS；建议PC p95 frame interval≤20ms、手机≤40ms，长任务>50ms统计；以真实连续游玩而非空白场景测。手机真机是发布门槛，Playwright模拟仅验证布局和事件。

| 指标 | 预算 |
|---|---|
| 初次下载 | 进入可玩所需网络传输总量≤10MB，含引擎和必要首批图集，不含后续按需音频 |
| 内存 | PC≤512MiB、手机≤256MiB（目标游戏相关JS/Worker/纹理估算+可用进程指标；记录测量口径，浏览器不一定提供精确总内存） |
| Chunk | 基础25加载/9活跃，按视口增加；初始硬上限49加载、16请求、Region LRU 16，G3校准 |
| 模拟实体 | 初始每活跃chunk≤24个动态对象，总≤216（玩家建造动物超出时降低远端刷新，禁止丢存档） |
| 路径规划 | 每帧最多2请求，单次≤512搜索节点初值；分帧处理与失效缓存 |
| 图集 | 1024/2048px；按需加载季节/室内，GPU纹理初始64MiB手机/128MiB PC预算 |
| 环境粒子 | 手机128、PC512初值，超预算降视觉效果不降玩法 |
| 区块激活 | 近邻预取、分帧创建，主线程每帧增量工作≤4ms初值 |
| 保存 | 每30s/关键操作；序列化分批，避免>50ms主线程阻塞；记录快照耗时及容量 |
| 长途 | 1000 chunk穿越后无持续内存增长；静止2分钟释放后内存较预热基线增幅≤15%（同一测量口径） |

## 优化顺序
先建立固定seed、镜头、模拟对象和输入回放。使用浏览器 Performance/Memory 记录脚本、布局、GPU/纹理（能取得时）、Worker耗时、chunk队列与实际活跃对象。优先减少图集切换、不可见对象、DOM重绘、跨线程拷贝；LRU和释放监听器。地表只渲染可见 tile，装饰/动物按距离降频；大地图用已探索摘要、按需绘制。轻/标准画质仅调DPR、粒子/光效/动画，不改变碰撞或农业产出。无证据不引入WASM或第二引擎。

## 场景与验收
PERF01 冷启动清缓存/暖启动分别测下载与可玩时间（建议20Mbps网络≤5秒冷启动目标，实测记录）；PERF02 连续15分钟穿越森林/河岸、村庄、农场、室内、雨雪；PERF03 固定1000chunk路径与两次住所传送，记录RSS/JS/纹理估算；PERF04 1000块农田+20建筑+12动物+满背包交易/离屏补算与自动存档；PERF05 低端档/旋转/后台恢复/断网。每场景至少3轮，公布p50/p95、失败/丢帧与峰值，不只选最佳结果。首次原型只验证代表场景；G6完整素材及内容重新测。服务器只传输静态文件，运行时不得调用模型、计算世界或写玩家状态。
