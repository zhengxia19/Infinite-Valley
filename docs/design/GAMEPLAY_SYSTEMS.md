# 游戏系统详细设计 D06
v1.0 · 2026-11-27 · 已确认机制，具体参数为初始平衡值
依赖 D02、D05；D07 管理内容数值，D08 管理动物及NPC。核心操作由模拟层验证并原子修改，渲染不得改状态。

## 角色、时间与体力 G03/G04
初始6件一级工具（斧、镐、锄、浇水壶、镰、钓竿）、萝卜种子10、帐篷1、金币200；春1日06:00、体力100。基础步速4 tile/s，八向归一化；碰撞按脚底矩形，不能穿水、树干、建筑。工具目标距离 Chebyshev≤1且视线不穿障碍；工具消耗见D07。走路不耗体力，无生命、死亡、饥饿、耐久。体力不足拒绝消耗操作；自然恢复建议坐下休息每游戏10分钟+5（实测调整），食物回复上限100。睡眠在帐篷/床附近，跳至下一日06:00且恢复100；同一天不得反复睡眠刷产出，跳转总是下一个06:00。日期以整型 gameMinute 从春1日00:00累积；每现实1秒1游戏分钟；28天/季、112天/年。日界00:00，季节按日号，睡眠经过的日界按顺序结算。隐藏、菜单、关闭不推进；绝不按现实时间补算。天气按世界 seed + day + season 确定（见D07），每个游戏日全球一致，雨雪视觉局部化。

## 背包与物品 G03
32格含8快捷格；普通物品堆叠99，工具/独立对象不堆叠；箱子32/64格。物品定义 ID 与实例状态分离。增加物品先合并现有堆，再用空格；操作整体预检容量。采集/收获/拆除/交易空间不足则不执行，不损资源；制作先模拟扣料再验收输出。工具不允许丢弃或卖出最后一件基础类型，升级直接替换同类型，避免软锁。整理稳定按类别+ID；储物箱拆除前必须清空。地面不引入无限物品掉落。初期不做装备栏、耐久或随机品质系统。

## 采集、熟练度、工具 G03/G06
选工具→验证范围/类型/体力/背包→进度动作（可被暂停）→扣体力、产出、改目标状态、加经验一次。移动取消未完成动作，无消耗；成功后一帧内视觉/音效反馈。树、石、杂草、可采植物按D08再生；被建造覆盖不得再生。农业、采集、钓鱼熟练度1–10，成功动作加经验；升级降低体力成本或提高操作效率但不修改原始世界随机分布。每次成功动作只发一次经验。三级工具：一级普遍可用、二三级效率提高；地表高级矿物需更高等级但基础材料永远可取得。升级材料/费用见D07。

## 农业状态机 G04
地表可耕草地/泥土→耕地→播种→成长→成熟→收获；耕地使用锄，种子消耗1；作物记录 cropId, plantedDay, growthDays, wateredDay, fertilizerId, nextHarvestProgress。浇水每日标记一次，雨天自动等效浇水（雪不等效）；每日00:00结算刚结束的一日，只有适宜季节且已浇水才增生长1；同日重复浇水无收益。成熟不会因当日缺水回退。季节跨界先结算前日，再按新季节枯萎/休眠；冬季可种指定作物，多季节牧草休眠规则见D07。收获仅成熟时，普通作物回空耕地、重复作物回生长阶段；丰产/肥料收益采用整数规则。洒水器覆盖本地3×3/5×5（去中心格）每日06:00执行，离屏按同一时序结算；新建当天可补手动浇水，不重复自动灌溉。浇水壶容量20，靠淡水补满不耗体力；无水不会自动消耗。种子加工1作物→2种子作为初值。种子可购买/野外获取，不能因资金用尽永久断粮。无温室、遗传、土壤退化。
离屏结算：每修改区块保留 lastSettledMinute/day，先按日期天气及设施状态补算，再应用新命令；只需处理已存在农田与设施，不能遍历未修改的无限地表。时序相同的在线/离屏结果一致；大跨度分批但加载时冻结交互至结算完成。

## 建造与室内 G05/G09
预制建筑按整数网格吸附，footprint、通行格、门位置、sprite anchor 分离。可建地表、无重叠、无未收获作物/动物、保护村庄区域、桥两端可达才允许；预览显示合法/原因。确认时扣材料、实例ID、占地和碰撞一起更新；不做施工等待。道路/围栏逐格放置，边缘自动衔接；桥模板限定连续水格+两端陆地。任何建筑都允许拆除并返还建造消耗的全部原料（按建造时记录的成本，不按当前价格），不返服务费；返材超容量拒绝；拆前箱子/加工队列清空，动物先迁移，住所登记先移除或选择新主住所，不可拆除当前所在室内的建筑。移动建筑不扣料，原位置/新位置原子替换，保留实例ID及室内、容器状态。禁止拆自然村庄、改河填海。
房屋内部独立场景，房屋 instanceId 对应室内 grid；门进入，出口返回门前安全格。允许床、储物箱、家具按网格放置；阻止封堵入口、床或唯一通路。初版不做任意房墙编辑、楼层或地下室。房屋升级时保留合法家具，无法容纳的升级拒绝并提示先移动。
帐篷或自有农舍登记住所，最多一个主要住所，可切换；无登记住所时隐藏回家功能。任意地表安全时允许回主住所，已登记住所之间传送；室内先出口或直接载入目的地地表安全点。传送不消耗金币、体力或游戏时间，加载失败保留原位置；不允许在提交中/存档异常中传送。不产生复制。

## 制作、加工、经济 G06/G08
手工配方与设施配方分开；检查配方、工具/设施、材料和容量，手工即时，设施按游戏分钟完成（D07）。设施记录投入与完成时间；一次投入只对应一次输出，容器满时停队列不丢失；拆除前清空。购买/出售稳定价，正整数数量与金币，商人可无限买卖指定普通品（动物/独立对象按位置约束）；禁止可买可卖物品存在即时套利；出货箱确认出售后在下一日00:00结算，离屏也结算，金钱入账一次。未付款前可取回未结算货物；关闭网页不进展。零金币恢复路径：可采野生植物/木石出售、采野生种子。详细NPC、家畜、鱼见D08。

## 验收
SYS01 任何失败动作状态完全不变；SYS02 零体力、零金币、满包均可恢复；SYS03 缺水、雨水、跨季、睡眠、离屏与在线结算一致；SYS04 建造/移动/拆除净材料守恒、箱子与室内保留；SYS05 两个住所互传且失败原地；SYS06 交易、加工、出货、升级刷新无重复。
