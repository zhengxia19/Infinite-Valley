# 单一共享世界与多人规则 D25
v2.0 · 2026-11-27 · C20确认；新增规则为设计初值，G3验证
## 世界与时间
部署仅一个 active worldId+worldEpoch；所有玩家/AI同地图、同世界种子/生成器版本、日历、资源和建筑。房屋内部是同世界的空间实例，不是独立世界；无分房匹配、多地图副本或P2P权威。只有管理员可以创建/销毁/换代，见D28。服务器重启加载同一世界，不自动重置。现实24分钟=游戏一天、28天/季、112天/年；至少一个有效在线角色时按服务端时钟推进，无人在线/维护/停机暂停。个人打开菜单、睡眠、下线不改变全局时间；睡眠仅恢复本人。在线一天可被多玩家共同经历，离线注册者的农场按已推进的游戏时间补算。非适季作物休眠、成熟保留；缺水不长，家畜不死亡；不因其他玩家加速而永久损失庄稼。管理员不能随意快进作为日常玩法；测试时钟仅隔离测试环境。
## 领地与保护
玩家可在公共出生区外任一合法地点申请32×32对齐的领地地块（初始按chunk对齐，每角色最多4块，可不连续，待负载和平衡验证；游客同额度）。先检查公共道路/河道保护带、村庄、已有领地/占地、他人对象；不可整块封堵自然交通/岸线。领地只授予改造权，公共地表可自由走动和采集野生资源；建造、开垦、围栏、道路、桥、动物住所必须在有权范围。桥须连接可通行陆地；公共桥由世界生成/管理员维护，不允许圈占公共路口。领地内保留必要通路；角色彼此不硬碰撞，无恶意堵门。无PVP、盗窃或破坏。玩家不能占用别人的地块；限制无主土地抢占；注册离线领地永久保存，暂无自动没收，长期废弃处理由管理员政策与审计（不自动删活跃资产）。解除领地需先搬迁/拆除资产、取消ACL；不得将他人财产一起删除。领地边界与权限显示在地图/建造预览。
## 所有权/协作
资源和设施唯一实例，ownerPlayerId及landId。公共资源谁先合法完成谁获得；资源再生共享。普通玩家可访问公共区域，私有室内由主人决定访客许可；无权限不能打开箱子、移动/拆除、收获、取动物产物。注册所有者可对注册协作者授权 visit/use/tend（照料/收获入所属容器），默认关闭；不授予管理、转让和拆除权限；可即时撤销，后续命令按最新ACL。资产只能存在一个归属；不做复杂公会、土地买卖和共享所有权。注册玩家间可双方确认直接交易物品/金币，原子交割；禁止中途修改确认、借此复制，断线取消。游客可完整探索、NPC经营、建造与养殖，但禁止玩家间资产转移、共同容器及可导致临时初始资产进入持久账户的协作（注册后解锁）；相同身份下人类AI一致。游客删除见D24，公共修改不回滚。
## 同步与公平
服务器唯一权威；玩家位置、动作、碰撞、资源、占地、库存、体力、金币、时间、权限与交易均验证。浏览器只预测运动/渲染/预生成可见底图/寻路。服务端固定20Hz初值，动作按真实游戏时间执行；快照/增量10Hz初值，事件可靠确认，断线重连取最新状态。每个角色基础3×3活跃、5×5可见加载；服务器按并集模拟、兴趣管理（AOI）仅发送附近公开对象和本人的私有状态；未授权领地箱子、其他背包/隐藏地图不下发。已探索地图/住所远处摘要可分页访问，但不实时模拟远区。所有改变按命令序列、版本、控制epoch验证；同资源竞争以服务端接受顺序为准，不以客户端时钟或模型速度排序。AI不得提速、跳时钟、直接写坐标或绕过可见范围，命令预算与人类相同。
## 社交范围
第一版支持看见其他角色、昵称/控制状态、相遇、合作、交易与访问邀请；可选最小预设互动/表情，不提供全局自由聊天、语音、公会、复杂经济或玩家脚本执行服务器。玩家和AI都能独立完成核心循环，协作非强制。管理与封禁见D28。
验收 MP01两个客户端同一世界、同资源竞争；MP02权限和占地；MP03离线/游客销毁不误删；MP04同时间/非适季休眠；MP05断线/增量/AOI；MP06双向交易守恒；MP07AI公平和人类接管。
