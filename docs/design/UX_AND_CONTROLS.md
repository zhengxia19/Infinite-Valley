# 用户体验与操作 D04
v1.0 · 2026-11-27 · 设计初值待真机体验；依赖 D02、D03

## 页面与状态
标题页→继续/新世界/导入/设置→角色与世界创建→载入→游戏。暂停菜单提供返回游戏、保存、导出、设置、返回标题。删除世界需明确确认名称；导入默认创建新世界，不覆盖原件。WebGL 不支持/存储失败显示说明，不让用户停留黑屏。
游戏状态为 loading / playing / paused / modal / hidden / saving-error。playing 才推进时钟；背包、交易、地图、建造选择和设置暂停，定位建造预览仍暂停时间；只有单独的移动定位模式允许走动且不推进时钟，原型验证是否保留。标签隐藏/失焦释放所有按键和触控并暂停；回到页面点击继续，不累积经过时间。工具操作、保存事务不因打开菜单重复执行。

## 布局
PC 线框：
```
[日期 季节 时刻 天气]                 [金币 体力 地图 设置]
                         世界画面
                  [1][2][3][4][5][6][7][8]
```
手机横屏：左上日期、右上体力金币/地图；左下虚拟摇杆，右下主工具、交互；底部中间8格快捷栏；弹窗全屏内可滚动。保留 safe-area，不遮 HUD；至少44 CSS px 主要触控目标（在紧凑屏幕可横向滚动快捷栏，不能缩成不可点）。竖屏显示横屏提示、允许退出和导出；不假定浏览器可强制旋转或全屏。字体随设备适配，游戏画面使用固定缩放档位（PC 1×/2×/3×候选，移动根据视口与 DPR 选取，待 G3）。UI 文本采用 DOM，不强制像素字体。

## 输入表
| 意图 | PC | 手机 |
|---|---|---|
| 行走 | WASD/方向键，八向归一化 | 左下虚拟摇杆，死区0.15初值 |
| 选择目标 | 鼠标指向地块 | 点选目标或面向前方格 |
| 工具 | 左键/按键 Space（不覆盖文本输入） | 使用按钮 |
| 交互 | E 或右键 | 交互按钮 |
| 快捷栏 | 1–8/滚轮 | 点选 |
| 背包 | Tab / I | 背包入口 |
| 地图 | M | 地图入口 |
| 建造 | B，预览、确认、Esc取消 | 选物、拖预览、确认/取消 |
| 缩放 | +/- 或 Ctrl+游戏画布滚轮（不劫持浏览器全局） | 两指捏合至固定档 |
| 暂停 | Esc | 暂停按钮 |

工具默认作用于玩家脚底格周围1格（含对角），不可隔着障碍。左键不隐式移动；远目标提示靠近。触屏摇杆和工具按钮必须支持不同 pointer ID 同时按压，pointercancel、blur 后归零。快捷栏滚轮与缩放不冲突。建造/交易只有显式确认才执行。所有键可重映射或提供基础替代；DOM 焦点内不触发移动。

## 交互细节
背包32格含8格快捷栏；支持拖放、点击选择/交换、拆分数量、快速转移和整理；工具独立一格。满包时不吞物品，收获/采集先校验接收容量，失败保留目标。建造显示 footprint、绿/红及原因、价格和返还说明。交易显示数量、总价、剩余金币；购买/出售原子执行。地图只绘制探索过的区域，支持缩放、标记、住所登记与回家；不生成全世界以供浏览。角色创建采用有限素材预设，避免无意义输入。

## 语言与声音
简中/英文词条使用稳定 key，切换无需新开世界；默认跟随浏览器语言（zh-CN否则英文），设置覆盖；文本、数值和日期本地化但存档 ID 不随语言改变。背景音乐、环境、操作音分别控制音量/静音；首次用户操作后启动音频，隐藏时停止/淡出。尊重减少动态效果设置（减少粒子和晃动，不改变模拟规则）。
