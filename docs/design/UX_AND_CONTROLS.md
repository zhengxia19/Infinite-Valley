# 用户体验与操作 D04
v2.0 · 共享世界；依赖D02/D03/D24/D25/D26
## 入口与状态
标题页只有「直接进入」「注册/登录」「设置」；无新建、选择、导入或删除世界按钮。展示服务可用/维护/满员。游客自动生成临时昵称，可修改外观；明确退出将销毁角色、临时建筑及未转正进度，退出前可注册或导出。注册原地升级保留角色与领地；失败不销毁游客。登录恢复同一角色、服务器世界中的住所与进度；已有控制者时显式确认接管。退出菜单：返回游戏、注册/登录、导出、设置、离开；无本地恢复按钮。网络断线显示重连倒计时；游客宽限期内可重连，超时销毁；注册角色断线保存并离线。客户端不能创建世界。
## HUD
左上全球日期/季节/天气；右上金币、体力、网络状态、在线/AI标识、地图/设置；底部8格快捷栏；地图、交易、背包、建造、权限面板按需。手机横屏左摇杆右工具/交互，安全区及至少44 CSS px主要触控目标，紧凑时快捷栏滚动。竖屏提示旋转，不强制全屏。PC 1280×720/1920×1080、手机横屏。玩家被遮挡时局部透明。其他玩家昵称和AI控制标识可见，不展示私密数据。AI接管时显示「AI控制中」及常驻「立即接管」按钮，人工移动/工具键可立即请求夺回，确认前停发动作。
## 操作
WASD/方向键或摇杆八方向；鼠标左键/使用按钮、E或交互按钮；1–8/点击快捷栏；Tab/I背包、M地图、B建造、Esc菜单；+/-或捏合固定缩放。输入焦点/失焦/隐藏释放移动意图；菜单只暂停个人操作，世界与作物继续。移动预测仅视觉，最终结果以服务端为准；网络等待显示pending，未确认不能展示为成功。交易/拆除/领地授权显式确认。拒绝返回原因：占地/权限/距离/体力/材料/满包/状态冲突/断线。其他角色不形成永久阻塞。
背包32格含8快捷栏，工具一格，普通堆99，拖放/触控等效、拆分/整理。地图只显示已探索及本人获授权摘要；主住所返回与已登记住所传送需权威验证。简中英文独立key，音量BGM/环境/操作分开，首次用户交互后播放，隐藏时静音。无强制任务、无全局暂停/时间快进。
## 验收
UX01–05：PC、真机横屏多触点、双语、网络断开与重连、交易/建造/满包反馈；新增UX06：游客退出提示与原地注册、已有登录接管、AI夺回、其他玩家菜单不影响世界时间。禁止把预测画面当已提交结果。
