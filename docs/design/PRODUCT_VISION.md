# 产品愿景 D01
版本 v2.0 · 2026-11-27 · 用户确认基线；细化指标待验证

## 定位
Infinite Valley（无限山谷）是一款可直接在浏览器游玩的单一共享在线、2D 正交俯视像素田园开放世界游戏。玩家从自然草地出发，自选家园，探索、采集、制作、建造、种植、养殖、交易。唯一世界由管理员创建、种子按需生成，所有人类与AI加入同一世界。不存在强制通关、主线任务或死亡压力。目标用户为喜爱自然探索、轻度经营、自由建造的 PC 和手机横屏玩家。

## 设计支柱
- VISION-01 自由：自由选择定居点、经营路线、多住所；不以任务锁定核心玩法。
- VISION-02 自然：河岸、道路、村庄、植被自然连续，探索有可识别地标。
- VISION-03 宁静：无饥饿、死亡、战斗；体力限制劳动，不限制行走；可暂停，个人离开不暂停共享时间。
- VISION-04 成长：从帐篷到农舍、自动灌溉、家畜和三级工具；交易和生产均能自我维持。
- VISION-05 持久：同种子和生成器版本生成相同初始世界，改造、探索、角色进度可服务端持久化、授权导出。
- VISION-06 本地优先：服务器仅承担权威游戏规则、状态同步、身份与持久化；客户端负责图形和非权威计算，服务器无GPU及模型推理。

## 验收与非目标
首个可玩切片须从游客加入唯一世界到探索、采集、制作、搭建住所、播种、收获、保存重载实际完成；V1.0 再补齐 C19 全量内容及共享在线、AI接入与 PC/手机、两种语言、音频、四季、室内、贸易等功能。见 D13、D17。探索无显著边界不是数学意义无限。性能、具体数值和艺术样片是设计者初值，须测试；不承诺未实测帧率。发布商业模式和域名未定；不阻塞本地设计。

依据：用户两轮确认；参考资料见 D18。

## 第三轮用户确认（覆盖冲突旧基线）
| ID | 决策 |
|---|---|
| C20 | 所有人类与AI进入同一共享在线世界，唯一正式世界；只有管理员创建/销毁 |
| C21 | 游客临时角色，退出销毁，可注册保留或主动导出 |
| C22 | 用户名+密码，不要求邮箱或手机号 |
| C23 | 注册玩家跨设备恢复角色及完整共享世界进度（非私人世界副本） |
| C24 | 正式Agent API、本地MCP、游戏Skill |
| C25 | AI可自主游玩或授权接管，人类随时接管；同规则同权限 |
| C26 | 建筑必须延续田园生活与自然开放世界两组主视觉；此前独立建筑图废弃 |
D24–D28 为新增专项契约。游客退出销毁的是角色及个人临时资产，不是共享世界；游客导出不能作为生产世界任意导入的凭证。单玩家睡眠和打开菜单不再推进/暂停全局时间。新增具体规则是设计初值，非用户逐项确认。
