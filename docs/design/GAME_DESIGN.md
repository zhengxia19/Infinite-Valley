# 游戏总体设计 GDD · D02
v2.0 · 2026-11-27 · 已按 C01–C19 形成设计基线；数值与体验待 G3/G4 实测
依赖 D01、D03；具体规则以 D05–D08 为准。

## 游戏体验
俯视视角共享在线开放世界；无主线强制任务、无通关结局。初始携带工具、种子、帐篷和少量金币，玩家自行寻找定居地点。设计支柱见 D01。不是模拟真实农业科学，也不是战斗生存 RPG。

### 三条核心循环
- 短循环：观察目标→选择工具→移动至作用范围→采集/耕种/交互→获得即时反馈与资源。
- 日循环：照料农田及动物→加工产品→交易/建造/探索→自主休息或睡觉。
- 长循环：扩大农场→升级工具→改善设施与家具→发现新生态区域、村庄及自然地标→建立其他住所。
每条循环都能单独带来满足感，不能以强制进度条替代实际玩法。

## 开局到第一次收获（切片目标）
玩家在春1日06:00出现。出生点附近有可耕草地、可达水源和资源；开始菜单提供简短非强制提示。砍树/采石获得材料，搭建帐篷、登记住所；锄地、播种、浇水。玩家继续探索或在线等待或休息，成熟后收获。注册后重连仍能看到同一角色、农田和其他玩家的共享世界变化。G4 交付须真实完成该闭环；不是仅展示 UI 或生成地图。

## V1.0 进阶
开局后无需解锁即可步行至所有可达区域。工具升级提高效率，不锁基础探索。利用基础野外资源交易，购买种子或家畜；通过种子加工、自动灌溉及生产设施降低劳动。村庄是自然聚落，不引入复杂社会关系。允许多住所、室内装饰，快速旅行不推进时间且不复制物品。无工具耐久。缺水停止生长，动物缺饲料停止生产不死亡。

## 难度与反馈
体力只限制劳动；行走、打开背包、传送、睡觉不受限制。目标不可交互、材料不足、地形不可建造时展示明确原因，不消耗资源或时间额外惩罚。错误操作不应锁死游戏。睡眠可在登记住所的床/帐篷使用；不强迫每天睡觉。无强制任务；非阻塞提示可关闭。睡眠仅恢复本人，不跳过世界时间。

## 内容与阶段边界
D07 控制内容规模，D08 控制 NPC/动物规则。地下世界、战斗、复杂社会及遗传系统为明确非目标。G4 是可玩切片不是 V1.0；G5 才补齐全部已确认内容。实际美术及数值需人工评审。验收：D13 G01–G12 全部追踪，不以功能数量替代体验。

## 多人增量规则（优先于旧单机措辞）
G13 唯一世界、人类/AI相遇、服务器权威、兴趣区域同步；G14 游客销毁/注册升级/跨设备；G15 领地、共享资源、协作与交易；G16 Agent API/MCP/Skill、控制权交接；G17 管理员唯一世界生命周期与恢复。两人争抢同一资源只允许一个成功；不允许擅改其他玩家的农田、资产。角色可见的其他玩家昵称、位置与控制模式，不暴露账户或背包。无玩家PVP。G4切片须两客户端真实同世界完成定居、首次收获与注册重连，包含一个AI客户端。全局日历、领地、游客退出和离线规则以D25为准；D24管理身份。
