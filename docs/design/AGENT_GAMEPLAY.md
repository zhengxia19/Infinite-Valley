# AI 游玩设计 D26
v2.0 · C24–C25确认；依赖D24/D25/D27
## 目标
人类和外部AI在唯一世界中共存。AI可以自己注册或用游客身份直接进入，也可经本人授权控制已有角色；注册角色可长期复用。AI不是NPC，不调用网站模型服务、不在服务器运行用户生成代码。无需AI的普通玩家完整可玩。
## 操作原则
同一身份、同一游戏时钟、移动速度、工具耗时、体力、交易、领地、权限、命令频率及可见信息。Agent只能读取本人状态、附近可见区域、已探索地图、被授权设施、公开内容规则；不读取隐藏资源、其他人私有状态、数据库或管理员接口。底图seed公开时不能保证防外部分析，但正式接口不主动暴露未探索资源；这与人类客户端相同。禁止指令完成任意目标、直接发金币、坐标瞬移、任意脚本eval或修改世界。高级动作仅为客户端合法命令编排，实际移动、采集、等待与结算必须发生于权威游戏引擎。
## 控制模式
普通人类、AI自主、AI授权接管；UI显示当前控制模式。唯一controllerEpoch由服务器生成，显式授权AI后旧写通道失效，人类点击立即接管或操作键可请求夺回；服务器先撤销AI lease/队列/在途未提交动作，再授予人类新epoch。已提交动作不回滚；取消或断线不得重复执行。授权可撤销、过期、绑定角色/会话/范围；AI独立身份也不能获得管理员权限。AI控制期间人类可以观察但不同时发送动作。人类重新接管不要求AI响应。
## 技能与操作
Agent API定义D27，本地MCP只转换协议，不另写模拟逻辑；游戏Skill教规则、接口、失败处理、观察→计划→执行→核对循环。模型推理与寻路在使用者机器/Agent服务承担，不需要网站GPU。建议技能：探索/观察、找可建地、采集、制作、开垦/种植/浇水/收获、交易、休息、存档导出。技能必须根据真实反馈调整，不假定固定地图坐标；可由用户自己的Agent记录经验，不上传程序到游戏服务器。游戏API工具返回结构化状态/事件，视觉截图只用于辅助与验收。
## AI游玩验收
AI01游客AI与人类同地相遇；AI02独立AI经正常工具完成定居→10格种植→实际日界→收获；AI03人类授权并接管，旧动作失效；AI04观察不泄漏、恶意越权/超速被拒；AI05同输入/规则同效果，AI和人类共享资源竞争；AI06本地MCP+Skill从真实外部Agent接入并可断线重连。用隔离测试世界执行自动化，不在正式世界刷资源或重置；测试时钟不开放生产。尚未集成验证。
